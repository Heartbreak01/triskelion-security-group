# Triskelion Security Group
Proyek website statis HTML dan CSS; seluruh data perusahaan fiktif.

## Struktur
- index.html: beranda, profil ringkas, ilustrasi, kapabilitas.
- profil.html: identitas, visi, misi, tabel profil, kontak simulasi.
- layanan.html: layanan dan tabel program.
- style.css: seluruh styling, layout, dan media query.
- lang-style.css untuk styling pemilihan bahasa (UPDATED)
- lang.js untuk opsi translasi pemilihan bahasa (UPDATED)

## Pemetaan rubrik
1. Profil dan gambar: index.html serta profil.html.
2. Tabel: profil.html dan layanan.html, dengan caption, thead, tbody, th, td.
3. Multipage: tiga HTML; menu dan tombol memakai anchor dengan href relatif.
4. Komponen: header, nav, main, section, article, aside, footer, div; CSS eksternal.
